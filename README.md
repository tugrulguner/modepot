# ModePot

The public home of the ModePot family: Dexpot, Intpot, and Summonpot.

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run check
npm run build
```

## Deployment

The static Astro build is deployed to Cloudflare Workers Static Assets.

```bash
npm run deploy
```

Production domain: `modepot.io`
